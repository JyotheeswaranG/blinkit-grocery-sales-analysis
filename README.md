# 🛒 Blinkit Grocery Sales Analysis

## 📊 Project Overview

This project presents an end-to-end **Grocery Sales Analysis** using **Python, SQL, Excel, and Power BI**.

The objective is to analyze grocery sales performance, product categories, outlet characteristics, customer ratings, and inventory-related indicators to identify meaningful business insights and support data-driven decision-making.

The project demonstrates the complete Data Analyst workflow:

**Data Collection → Data Cleaning → Exploratory Data Analysis → SQL Analysis → KPI Development → Power BI Dashboard → Business Insights**

---

## 🎯 Business Objectives

The key objectives of this project are:

- Analyze overall grocery sales performance.
- Identify high-performing and low-performing product categories.
- Compare sales across different outlet types and sizes.
- Analyze sales by outlet location tier.
- Understand the impact of product fat content on sales.
- Analyze customer ratings and product performance.
- Examine item visibility and pricing patterns.
- Identify top-performing products and outlets.
- Develop an interactive Power BI dashboard for business reporting.
- Provide actionable recommendations for improving sales and inventory decisions.

---

## 🗂️ Dataset

The project uses the **Blinkit Grocery Sales dataset** containing approximately **8,500+ records** of grocery products and outlet-level sales information.

### Key Dataset Attributes

| Category | Fields |
|---|---|
| Product | Item Identifier, Item Type |
| Product Attributes | Item Weight, Item Fat Content |
| Visibility | Item Visibility |
| Pricing | Item MRP |
| Outlet | Outlet Identifier, Outlet Type |
| Outlet Details | Outlet Size, Outlet Location Type |
| Outlet History | Outlet Establishment Year |
| Performance | Sales |
| Customer Feedback | Rating |
